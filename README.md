# java-racingcar-precourse

## 필요한 기능

1. 출력 기능

    1-1. 자동차 이름 입력 메세지 출력

    1-2. 시도 횟수 입력 메세지 출력

    1-3. 실행 결과 메세지 출력

    1-4. 차수별 실행 결과 출력

    1-5. 우승자 안내 메세지 출력


2. 입력 기능

    2-1. 자동차 이름 입력

    2-2. 시도할 횟수 입력


3. 자동차 경주 게임 관리 기능

    3-1. 입력된 자동차 이름의 개수만큼 자동차 생성

    3-2. 입력된 시도 횟수만큼 각 자동차의 전진 로직 호출

    3-3. 게임 종료 후 가장 많이 전진한 자동차의 이름 출력


4. 자동차 기능

    4-1. 전진 로직: 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우


5. 검증 기능

    5-1. 입력된 자동차의 이름이 5자 이하인지 검증

    5-2. 입력된 시도 횟수 검증
